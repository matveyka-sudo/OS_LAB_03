# Основа оформления

Источник: https://github.com/Yadroff/OS_report_template (изучен 19.10.2026).
Стиль `styles/log-style.sty` взят из шаблона, лицензия MIT сохранена отдельно.
Оставлены A4, 12 pt, поля 2,54 см, оформление разделов и листинга.
Титульная страница повторяет структуру шаблона, личные данные не заполнены.
Исходники разбиты на главный файл, титульный лист и текст отчёта.

Изменения: вместо inputenc/fontenc/tempora используется fontspec для Unicode
и Times New Roman (либо TeX Gyre Termes). Компилятор: XeLaTeX/Tectonic.
Добавлена нумерация страниц, нижний колонтитул отнесён на 10 мм.
Это адаптация шаблона для доступного компилятора на macOS.

Отдельный Word-файл с требованиями к этой работе не приложен.
Существующие документы прошлых лабораторных не подменяли собой требования.
Полный код C включён автоматически, в отчёт добавлен реальный вывод `ps -M`.
`strace` из примера шаблона на macOS не запускался: он предназначен для Linux;
вывод системных вызовов не выдуман. Обязательная демонстрация потоков выполнена через ps.

Для исключения чрезмерных межсловных пробелов основной текст выровнен
по левому краю; титульная страница, таблицы и графики сохраняют своё выравнивание.
